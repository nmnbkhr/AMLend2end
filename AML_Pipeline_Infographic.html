12-Step Pipeline

01
Create Feature Groups
PySpark feature engineering — encode transaction types and build graph edge list from raw CSV data.
nb: 1_create_feature_groups → edges_td.csv, node_td.csv
02
Prepare Embedding Dataset
Format and clean graph edges for Node2Vec embedding training input.
nb: 2_prep_training_dataset edges_td.csv → cleaned edge list
03
Embedding HP Tuning
Search walk_length, walk_number, embedding_size, p, q parameters using Maggy framework.
⚡ optional nb: 3_maggy_node_embeddings → best_hp.json
04
Compute Node Embeddings
Biased random walks via Node2Vec → Word2Vec training. Captures structural patterns in the transaction network.
nb: 4_compute_node_embeddings → 32-dim embedding per node
05
Create Embeddings FG
Combine node embeddings with binary SAR labels into a unified feature group for model training.
nb: 5_create_embeddings_fg → embeddings_fg.parquet
06
Train/Eval Split
Split 32-dimensional embeddings and binary labels into training and evaluation sets.
nb: 6_create_anomaly_td → X/y_train.npy, X/y_eval.npy
07
GAN Hyperparameter Tuning
Search latent_dim, n_layers, activation, dropout_rate, and learning rate for the GAN.
⚡ optional nb: 7_maggy_adversarial → gan_best_hp.json
08
Train GAN Anomaly Detector
Train Encoder→Decoder (Autoencoder) + Discriminator. Learn reconstruction threshold from anomaly scores.
nb: 8_train_adversarial_aml → .keras model + threshold.npy
09
Model Inference Testing
Validate model predictions on test nodes before dashboard and report generation.
nb: 9_aml_model_server → anomaly scores + predictions
10
Visualize Results
Generate executive dashboard, anomaly distribution, top anomalies, transaction network, and pattern summary plots.
nb: 10_visualize_results → plots/ (6 PNG files)
11
Analytical Dashboard
Generate a full interactive HTML report with metadata and a portable ZIP bundle for distribution.
nb: 11_analytical_dashboard → report.html + run_bundle.zip
12
AML Pattern Analysis
Detect AML typologies: fan-out, hub, cycle, and structuring patterns. Generate case files and risk queues.
nb: 12_aml_pattern_analysis → cases/ + risk_queue.parquet

AML Typologies Detected

🌊

Fan-Out

Single source distributing funds to many destinations to obscure the trail

🕳️

Hub

High-degree intermediary nodes acting as money laundering chokepoints

🔄

Cycle

Circular money flows that return funds to origin through layered transfers

📐

Structuring

Frequent small transfers below reporting thresholds to avoid detection
